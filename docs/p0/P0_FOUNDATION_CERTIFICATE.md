# P0 Foundation Certificate

Status: locally certified; remote PR CI evidence must still match the containing commit before review readiness is declared.

This certificate is limited to greenfield independence, legacy contract/test mapping, planned-scenario completeness, active foundation harnesses, CI readiness, and OX handoff readiness. It does not certify Customer, Merchant, Captain, Admin, backend, commerce, payment, delivery, appointment, inventory, loyalty, security, operational, or platform production readiness.

The containing commit is eligible for P0 review only after `pnpm validate:all` passes twice from clean checkouts at that exact SHA, adversarial gates pass, reference-tree hashes remain unchanged, and every PR check succeeds. The PR description is the durable evidence record for command output, timestamps, exact SHA, and CI links.
