# Dusky-V1.1 Agent Rules

This repository is greenfield. Never merge, cherry-pick, or wholesale-copy MyPetNew or the legacy archive. Legacy sources are read-only evidence; every extracted behavior must retain provenance.

Work on an isolated branch/worktree and on bounded contract IDs. A planned contract becomes active only in the same change that adds production behavior, executable tests, test paths, focused evidence, full validation, and registry status. Never weaken or delete an active contract, disable a test, add fake assertions, bypass PostgreSQL integration checks, or require production credentials.

Before requesting review, run `pnpm validate:all`, report exact commands and SHA, push the branch, and open a PR. Do not merge or enable auto-merge. Only the user authorizes merge.
